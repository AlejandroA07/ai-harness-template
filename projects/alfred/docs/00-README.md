# Alfred — Docs index

Two documentation roots, one rule: product truth and implementation truth never mix.

| Folder | What it holds | Start at |
|---|---|---|
| `planning/` | Product truth: vision, MVP scope, architecture choice, finance/sharing model, collections. Read before any product-level decision. | `planning/00-README.md` |
| `dev/` | Implementation truth: how it's actually built, living topic docs (finance, testing, security, database), the implementation decisions log, milestone reports, session handoffs. | `dev/00-README.md` |

Docs model: living topic docs are updated in place (current truth); dated reports and log entries are history and never edited after the fact. Full spec lives in the harness template (`global/skills/wrap-branch/docs-model.md`).
