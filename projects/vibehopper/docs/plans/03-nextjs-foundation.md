# Phase 3: Next.js Foundation

Status: Planned outline

Branch: `frontend-foundation`

## Outcome

Deliver a public, server-rendered event list and event detail experience.

## Planned Work

- Scaffold Next.js App Router with TypeScript, Tailwind CSS, ESLint, and Turbopack.
- Generate API types from the Phase 2 OpenAPI document.
- Implement `/` and `/events/[id]`, with filters represented in URL search parameters.
- Cover responsive, accessible loading, empty, error, and not-found states.
- Add unit/component tests, Playwright smoke coverage, and frontend checks to the root gate.

Authentication, maps, event writes, and ingestion remain out of this phase.
