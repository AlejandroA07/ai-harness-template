## Topic docs vs reports

**Topic docs** are *current truth* — updated in place when behaviour changes. **Reports** are *history* — a dated snapshot of a finished branch, never edited after the fact. When you need to know how something works now, read a topic doc; when you need to know how a branch went, read its report.
